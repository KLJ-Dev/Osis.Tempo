# 🕒 Osis.Tempo

**개인의 하루 일정을 계획하고 관리하는 Java/Spring Boot 기반 웹 스케줄 관리 서비스입니다.**

PC와 모바일에서 동일한 일정을 관리하고, 하루의 흐름과 생활 리듬을 체계적으로 관리할 수 있도록 설계한 프로젝트입니다.

## 🧱 4. 아키텍처 설계

### 4.1. REST API 기반 구조

React 프론트엔드와 Spring Boot 백엔드를 REST API로 분리합니다.

PC와 모바일 브라우저는 동일한 백엔드 API를 통해 일정 데이터를 관리합니다.

### 4.2. 역할 분리

백엔드는 다음 계층으로 구분합니다.

| 계층 | 역할 |
|---|---|
| Controller | HTTP 요청 및 응답 |
| Service | 일정 관련 비즈니스 로직 |
| Repository | 데이터 접근 및 영속성 |
| Entity | 데이터베이스 매핑 |
| DTO | API 요청 및 응답 데이터 |

PostgreSQL을 데이터 저장소로 사용하고 Spring Data JPA를 통해 연동합니다.

> 현재 아키텍처는 초기 설계안이며 실제 구현이 완료되었다는 의미는 아닙니다.

### 4.3. AI 협업 원칙

- 작업 전 `README.md` 및 제작지시서를 우선 확인합니다.
- 프론트엔드는 GPT 중심으로 개발합니다.
- Java/Spring Boot 및 PostgreSQL은 사용자가 직접 개발하는 것을 원칙으로 합니다.
- 코드 변경은 별도 브랜치에서 수행하고 Pull Request로 보고합니다.
- PR에는 변경 전후 차이, 수정 이유, 영향 범위 및 테스트 결과를 명시합니다.
- 사용자 승인 전에는 기본 브랜치에 병합하거나 배포하지 않습니다.
- AI는 코드 생성을 지원하되, 코드의 이해와 최종 결정권은 사용자에게 있습니다.
